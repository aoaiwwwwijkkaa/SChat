# SChat
A safety chat for Roblox. Made because the Age Verification is really separating groups of people.

This project uses <b>Rojo</b> (https://rojo.space) for actually getting this in your experience.

To add in your own words/messages you must head into the <b>Setup</b> script located in <b>StarterPlayerScripts</b> and edit the example to your desire, then follow the instruction at <i>line 10</i>.
